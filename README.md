# Sistema de Inventario y Ventas Simple

Sistema web desarrollado en PHP y MySQL que permite gestionar productos y registrar ventas (módulo de productos completo).  
Cumple con buenas prácticas de programación, estructura por capas, validaciones y seguridad básica.

## Requisitos

- PHP 7.4 o superior
- MySQL 5.7 o superior
- Servidor web (Apache / Nginx)
- Navegador moderno
