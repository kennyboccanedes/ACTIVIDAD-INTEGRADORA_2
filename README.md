Sistema de Inventario - PHP y MySQL



&nbsp;Descripción

Sistema web básico que permite gestionar productos mediante un CRUD

(Crear, Listar, Editar y Eliminar), desarrollado en PHP y MySQL.



&nbsp;Funcionalidades

\- Crear productos

\- Listar productos

\- Editar productos

\- Eliminar productos



&nbsp;Validaciones

\- El nombre del producto no puede estar vacío

\- El stock no permite valores negativos

\- El precio debe ser mayor a 0



&nbsp;Requisitos

\- PHP

\- MySQL

\- Servidor local (XAMPP o similar)

\- Navegador web



&nbsp;Instalación

1\. Copiar el proyecto en la carpeta `htdocs`

2\. Importar el archivo `sql/productos.sql` en phpMyAdmin

3\. Ejecutar el proyecto desde el navegador



&nbsp;Base de Datos

El script SQL se encuentra en la carpeta `sql/`
